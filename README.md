# Accounting App

会計ソフトのMVPを構築するためのリポジトリです。FastAPI + PostgreSQL + Next.js を前提に、
仕訳入力から試算表・PL/BSまでの最小機能を段階的に実装します。

## 目的
- 仕訳入力と帳票出力を中心とした堅実な会計MVPを構築する
- 監査性の高い運用（確定後は修正仕訳で追跡）を前提にする
- 将来的な拡張（請求書、銀行連携、電子帳簿保存法など）に耐える基盤を作る

## MVP機能
- 勘定科目マスタ（科目コード/名称/区分：資産・負債・純資産・収益・費用）
- 仕訳入力（ヘッダ + 明細、複数行対応）
- 仕訳の整合性チェック（借方合計 = 貸方合計）
- 総勘定元帳（科目別の仕訳一覧）
- 試算表（期首/当期/期末残高）
- PL/BS（シンプル版）
- CSV入出力（仕訳インポート/エクスポート）
- 監査ログ（誰がいつ何を変更したか）

## 重要ルール
- 1仕訳（伝票）内で借方合計 = 貸方合計（アプリ側チェック + DB側担保）
- 仕訳確定後の変更は禁止し、修正仕訳で追跡する

## 推奨アーキテクチャ
- Webアプリ + API + RDB（PostgreSQL）
- API: FastAPI
- フロント: Next.js
- 認証: ロール（管理者/経理/閲覧） + 監査ログ

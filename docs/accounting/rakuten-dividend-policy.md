# 楽天証券 VTI 配当金の会計処理方針

最終更新: 2026-10-20

## 1. 目的

akmic合同会社の楽天証券で保有する VTI（Vanguard Total Stock Market ETF）の配当金について、Supabase 会計DBでの標準仕訳、為替換算、米国源泉税・国内源泉所得税の扱い、および2021〜2024年度の過年度訂正履歴を記録する。

この文書を会計システム実装上の正本とし、今後の楽天証券インポーターや手動訂正は本方針に合わせる。

## 2. 今後の標準仕訳

2025年度以降は、配当金の受取ごとに1仕訳を作成する。

基本形:

```text
借方  預け金 / 楽天証券 外貨預け金        手取額
借方  仮払金 / 楽天証券 米国源泉税         米国源泉税
借方  仮払金 / 楽天証券 国内源泉所得税     国内源泉所得税
貸方  受取配当金 / 楽天証券                 税引前配当金
```

借方合計と貸方合計は必ず一致させる。

配当の受取日ごとに仕訳を作成し、年間一括仕訳には戻さない。

## 3. 為替レートの保存

配当金は受取ごとに、少なくとも次の情報を `source_data` または仕訳メモに保存する。

- 税引前配当額（USD）
- 税引後受取額（USD）
- 申告レート
- 参考為替レート
- 円換算した税引前配当額
- 米国源泉税（USD / JPY）
- 国内源泉所得税（USD / JPY）
- 円換算した手取額
- 元CSVの識別情報

円換算は楽天証券CSVの `申告レート` を優先する。申告レートが存在しない過年度データは、元資料で確認できるレートを採用し、推定・代替を行った場合はその根拠を `source_data` に明記する。

## 4. 源泉税の科目

米国源泉税と国内源泉所得税は、費用科目の「租税公課」ではなく、税額控除・還付等の検討ができるよう次の資産科目で管理する。

```text
仮払金 / 楽天証券 米国源泉税
仮払金 / 楽天証券 国内源泉所得税
```

過年度に「租税公課」で処理していたものは、元仕訳を削除・変更せず、追加の振替訂正仕訳で上記の仮払金へ振り替える。

## 5. 過去の確定仕訳の扱い

Supabase上の `posted` 仕訳は原則として削除・直接変更しない。

過年度訂正は以下の方式とする。

1. 元仕訳を保存する。
2. `source_system = historical_correction` の追加仕訳で訂正する。
3. `source_record_id` を一意に設定する。
4. 訂正理由、元伝票番号、計算根拠を `source_data` に保存する。
5. `audit_logs` に訂正履歴を残す。

これにより、MFクラウド時代の元仕訳と訂正後の会計処理を両方追跡できるようにする。

## 6. 年度別の履歴

### 2021年度

元伝票: No.351（2022-10-31）

元仕訳:

```text
借方  預け金 / 楽天証券                  18,875
借方  租税公課 / 所得税等                 5,886
貸方  受取配当金 / 楽天証券              24,761
```

元資料:
- 税引前: 166.35 USD
- 税引後: 126.81 USD
- 期末換算レート: 148.85円/USD

訂正伝票: `HC-RK-2021-TAX`

```text
借方  仮払金 / 楽天証券 米国源泉税         2,477
借方  仮払金 / 楽天証券 国内源泉所得税     3,409
貸方  租税公課 / 所得税等                  5,886
```

結果として元の租税公課を打ち消し、源泉税を2種類の仮払金に振り替えた。

### 2022年度

元伝票: No.472（2023-10-31）

元仕訳:

```text
借方  預け金 / 楽天証券                  77,892
借方  租税公課 / 配当等                  24,299
貸方  受取配当金 / 楽天証券             102,191
```

元資料:
- 税引前: 688.16 USD
- 税引後: 524.53 USD
- 換算レート: 148.5円/USD

訂正伝票: `HC-RK-2022-TAX`

```text
借方  仮払金 / 楽天証券 米国源泉税        10,220
借方  仮払金 / 楽天証券 国内源泉所得税    14,079
貸方  租税公課 / 配当等                   24,299
```

2021年度と同じ考え方で、既存の租税公課を源泉税仮払金へ振り替えた。

### 2023年度

配当仕訳そのものが帳簿に計上されていなかったため、年間一括ではなく受取4回を個別に追加した。

| 受取日 | 税引前配当 | 米国源泉税 | 国内源泉所得税 | 手取額 |
|---|---:|---:|---:|---:|
| 2023-12-29 | 42,603 | 4,260 | 5,871 | 32,472 |
| 2024-03-29 | 45,029 | 4,502 | 6,205 | 34,322 |
| 2024-07-04 | 54,503 | 5,450 | 7,511 | 41,542 |
| 2024-10-03 | 47,477 | 4,748 | 6,543 | 36,186 |
| 合計 | 189,612 | 18,960 | 26,130 | 144,522 |

各配当は次の形式で仕訳した。

```text
借方  預け金 / 楽天証券                 手取額
借方  仮払金 / 楽天証券 米国源泉税      米国源泉税
借方  仮払金 / 楽天証券 国内源泉所得税  国内源泉所得税
貸方  受取配当金 / 楽天証券             税引前配当金
```

また、外貨預け金の期末帳簿価額との整合のため、`HC-RK-2023-FX` で為替差益 5,017円を追加した。

### 2024年度

元伝票: No.978（2025-10-31）

元仕訳:

```text
借方  預け金 / 楽天証券 外貨預け金      174,581
貸方  受取配当金 / 楽天証券             174,581
```

元仕訳は年間一括であり、源泉税が分離されていなかった。

楽天証券CSVを再確認した結果、年度合計は以下とした。

- 税引前配当: 219,576円
- 米国源泉税: 21,958円
- 国内源泉所得税: 30,261円
- 税引後帳簿額: 167,357円相当
- 為替差益調整: 7,224円

訂正伝票: `HC-RK-2024-DIV-FX`

```text
借方  仮払金 / 楽天証券 米国源泉税        21,958
借方  仮払金 / 楽天証券 国内源泉所得税    30,261
貸方  受取配当金 / 楽天証券               44,995
貸方  為替差益                              7,224
```

これにより、元の受取配当金174,581円 + 訂正44,995円 = 税引前配当219,576円となる。

2024-12-30分は楽天証券CSVの申告レート・税額欄が空欄だったため、元資料にある参考レートと標準的な税率関係から一部を再構成した。推定を含むことを `source_data` に記録している。

## 7. 2025年度以降

楽天証券インポーターでは、配当受取ごとに個別仕訳を作る。

今後は以下を標準とする。

- 受取ごとに1仕訳
- 受取配当金は税引前金額
- 米国源泉税と国内源泉所得税は別々の仮払金
- 手取額は外貨預け金
- 為替レート・USD金額・税額を `source_data` に保存
- 同一CSVを再取込しても重複しないよう `source_record_id` を一意にする

## 8. 税務申告との関係

会計帳簿の訂正と法人税申告書の訂正は別管理とする。

過年度の源泉税・外国税額について、所得税額控除・外国税額控除・還付等を検討する場合でも、会計仕訳を再度書き換えず、申告手続の結果に応じて必要な決済・振替仕訳を追加する。

2021〜2024年度の申告書については、当時の申告内容と現在の会計内訳が異なる年度があるため、申告訂正を行う場合は別表六等と照合して処理する。

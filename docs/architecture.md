# アーキテクチャ

## 構成
- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- 認証/認可: RBAC（管理者/経理/閲覧）

## 主要コンポーネント
- Web UI: 仕訳入力、帳票閲覧、マスタ管理
- API: 仕訳・帳票・マスタ・CSV入出力の提供
- DB: 勘定科目、仕訳、監査ログを保持

## データフロー
1. フロントから仕訳入力
2. APIでバリデーション（借貸一致、勘定科目存在確認）
3. DB保存 + 監査ログ記録
4. 集計APIで元帳/試算表/PL・BSを取得

## 監査・整合性
- 確定仕訳の更新禁止（修正仕訳のみ）
- 監査ログで誰がいつ何をしたかを記録
- 借方/貸方合計はアプリ側チェック＋DB側検証を併用

## 環境構成（案）
- 開発: Docker Compose
- 本番: コンテナ + マネージドPostgreSQL

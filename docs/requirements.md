# 要件・スコープ

## 目的
- 中小規模の会計業務を対象に、仕訳入力から帳票出力までをMVPとして提供する。
- 監査性・整合性を担保し、確定後の仕訳は修正仕訳で追跡する。

## 想定ユーザー
- 管理者（設定・権限管理）
- 経理担当（仕訳入力・帳票確認）
- 閲覧者（帳票参照のみ）

## MVP機能
1. 勘定科目マスタ管理
   - 科目コード、科目名、区分（資産/負債/純資産/収益/費用）
2. 仕訳入力
   - 仕訳ヘッダ + 明細（複数行）
   - 借方合計 = 貸方合計チェック
   - 伝票番号の自動採番
3. 総勘定元帳
   - 科目別の仕訳一覧
4. 試算表
   - 期首/当期/期末残高の表示
5. PL/BS（簡易版）
   - 期間指定で集計
6. CSV入出力
   - 仕訳インポート/エクスポート
7. 監査ログ
   - 変更履歴（作成/更新/確定/修正）

## 非機能要件（MVP）
- データ整合性: 借方/貸方合計の一致
- 監査性: 確定後の直接更新は禁止、修正仕訳のみ許可
- 権限: 管理者/経理/閲覧のロール

## 将来拡張（MVP外）
- 請求書/入金管理
- 銀行API連携
- 電子帳簿保存法対応
